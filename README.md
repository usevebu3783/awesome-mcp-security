## 🔐 What are the Security Checks?

awesome-mcp-security looks at nine important areas:

1. Prompt Injection – detects if harmful commands can change how the system behaves.
2. Toxic Flows – finds conversations that could lead to harmful or inappropriate content.
3. Attack Surface Risks – spots weak points that attackers might use.
4. Model Context Protocol (MCP) Compliance – checks if servers follow good rules for data handling.
5. Trust Score – an overall rating based on all tests.
6. Data Privacy – ensures servers handle user data safely.
7. Update Frequency – how often the server fixes problems.
8. Access Controls – who can use or change the server.
9. Response to Threats – how fast the server reacts to attacks.

Each test gives a clear result that you can understand, no technical background needed.
